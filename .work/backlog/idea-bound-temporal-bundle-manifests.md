# Bound inline temporal bundle manifests

During manual testing with Krometrail v1.0.3, a successful five-second temporal debug bundle over 52 frames generated nine artifact resources and useful summary evidence, but its inline artifact manifests expanded the structured response to roughly 44,000 tokens. The resource links already provide progressive access to the artifacts; preserve the compact summary and provenance needed for reasoning while avoiding automatic context saturation from every complete manifest.
