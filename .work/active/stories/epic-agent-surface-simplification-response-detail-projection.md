# Project canonical results into concise, expanded, and full responses

After canonical result acquisition, derive an implicit concise response, bounded expanded context, or the complete acquired full structure. Concise snapshots are flattened exact-target indexes ranked focused, editable, other non-link, then link with canonical preorder ties. Each target carries a complete `NodeReference`, role, name, value, and acquired accessibility states.

Expanded adds bounded flattened semantic entries with original parent/depth hints but does not reconstruct a pruned canonical tree. Report source node omissions separately from exact presentation omissions. Apply the detail consistently to live/root snapshots, page inspection, actions, batch final evidence, status, temporal bundles, and growing progressive-evidence collections. Keep inline image filtering orthogonal and preserve outcome, anchors, warnings, errors, capture degradation, range handles, and resources at every level.

## Acceptance evidence

- Default live and snapshot responses contain bounded flat targets with directly reusable generation-scoped references and no ancestor closure.
- A large snapshot retains a late focused/editable control ahead of early links and obeys count/serialized-byte bounds deterministically.
- Expanded adds bounded page/semantic context; full exposes the complete acquired structure; source and presentation omissions remain distinct and exact within their authority.
- One canonical result has identical authoritative envelope fields across all detail levels.
- False inline transport removes only inline image content/metadata selected for transport and never resource authority; true embeds verified bytes.
- Old tree-pruning, omission-marker, per-part switch, and compatibility-wrapper code is deleted.

## Implementation evidence

- Concise snapshots now emit bounded ranked `targets` with complete reusable node references and separate source/presentation omission counts.
- Expanded snapshots add bounded flattened semantic context; full retains the complete canonical snapshot and temporal bundle.
- Progressive frame/artifact responses keep bounded drill-down handles in concise mode and preserve acquired structures at higher detail.
- Inline pixels are fetched and emitted only on explicit opt-in, independently from structured detail and resource links.
- Replaced ancestor-closure and projection-matrix coverage with ranking, byte-bound, progression, protocol, and inline-transport tests.
