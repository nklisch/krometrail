# Canonical Model-to-Artifact Generation

Generate committed JSON samples and JSON Schemas from Rust contract types, then test canonical bytes and digests against checked-in artifacts.

## Rationale

Benchmark definitions, run manifests, and evaluation results use the Rust model as their source of truth rather than hand-maintained JSON/schema copies.

## Examples

- `crates/temporal-evaluation/src/bin/generate-benchmark-definition.rs:17` — emits canonical definition bytes and generated schema.
- `crates/temporal-evaluation/src/bin/generate-run-manifest.rs:17` — emits the sample manifest and schema from Rust contracts.
- `crates/temporal-evaluation/src/bin/generate-evaluation-result.rs:17` — emits canonical result bytes and schema.
- `crates/temporal-evaluation/tests/contracts.rs:53` — checked-in artifacts are decoded, validated, and digest/byte checked.

## When to Use

Use for checked-in schemas, fixtures, manifests, evidence envelopes, and externally consumed contract artifacts.

## When Not to Use

Avoid for internal runtime values or intentionally illustrative documentation snippets.

## Common Violations

- Hand-editing generated JSON.
- Maintaining an independent schema.
- Omitting canonical serialization.
- Failing to compare generated bytes and digests in tests.
